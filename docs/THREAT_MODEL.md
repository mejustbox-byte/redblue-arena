# Модель угроз — офлайн MVP (исторический документ)

Эта модель относится к версии 0.1.0. Актуальная модель локальной платформы 0.2.0: [THREAT-MODEL.md](../THREAT-MODEL.md); эксплуатационные ограничения: [OPERATIONS.md](../OPERATIONS.md). Историческое описание ниже сохранено для контекста и не описывает текущий control plane.

Активы: конфигурация лаборатории, целостность синтетических событий, findings и отчёт. Доверенная граница: оператор запускает проверенный код в своём окружении. Входная конфигурация считается недоверенной.

| Угроза | Контроль MVP | Остаточное ограничение |
| --- | --- | --- |
| Запуск вне scope | Явная авторизация, точный allowlist, только lab:// | Разрешение декларирует оператор |
| Инъекция команд или плагинов | Фиксированный реестр, отсутствие shell/network API | Изменённый исходный код доверять нельзя |
| Неверная телеметрия | Проверка цели, последовательности и synthetic | Только один формат событий |
| Чрезмерный ввод | 64 KiB конфигурация, до 100 целей, фиксированные 6 событий | Нет сервисных квот: сервис отсутствует |
| Подмена отчёта | Проверяемая детерминированная структура | JSON не подписан и изменяем |
| Утечка секретов | Синтетические данные без credentials | Оператор отвечает за окружение и перенаправление stdout |

Перед облачным релизом: проверка tenant isolation, RBAC, сетевой scope и deny-by-default egress, лимиты ресурсов, приватное хранение отчётов, устойчивый аудит и тесты отказа. Декларация `authorized` не заменяет эти меры.
