# Installation

Проект находится на начальной стадии. Рабочий запуск выполняйте только в изолированной тестовой среде.

1. Клонируйте репозиторий.
2. Создайте отдельное виртуальное окружение или контейнерный профиль.
3. Настройте allowlist учебных адресов и запрет выхода к production.
4. Запускайте только синтетические сценарии и проверяйте audit log.

Команды запуска будут добавлены вместе с первым MVP. Не используйте проект на чужих системах.
