# RedBlue Arena

Модульная лабораторная платформа для безопасной эмуляции атак и проверки обнаружения.

## Назначение

Red Team-сценарии запускаются только против заранее определённых учебных целей, а Blue Team-модули принимают телеметрию, применяют правила и формируют отчёты. Проект не предназначен для эксплуатации чужой инфраструктуры.

## План модулей

- `attack-sim`: безопасные сценарии эмуляции;
- `telemetry`: нормализация логов и событий;
- `detections`: правила и корреляция;
- `dashboard`: управление лабораторией и отчёты;
- `tests`: воспроизводимые интеграционные проверки.

## Принципы

Containment, минимальные привилегии, audit log, явный allowlist целей и отсутствие реальных секретов.
